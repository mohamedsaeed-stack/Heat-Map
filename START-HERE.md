## Traps already paid for — do not rediscover these

- **Nominatim's first result is often not the place.** Accepting it gave Hatta a road 90 km from the
  town and Al Fahidi a shop; 13 of 90 were transport features, with no error raised.
- **Overpass returns zero elements with no error when throttled.** An empty response is treated as
  throttling, never as an answer.
- **"Dubai" in Nominatim is the city, not the emirate.**
- **CARTO Voyager stamps "API KEY REQUIRED" across every tile** while firing a normal tile-load
  event, so no automatic check catches it. Only looking at the page does.
- **The artifact viewer blocks external stylesheets.** The page builder refuses to build if one
  would slip in.
- **Backticks inside a shell string get executed.** This shredded the README once. Use the Write
  tool for files.
- HubSpot's own traps are in `lookups/audit-repo-START-HERE.md`: the 500-row cap, cross-object
  fan-out, group-by undercount, and the mislabelled stage ids.
